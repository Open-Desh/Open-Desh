# Open Nation Context & Development Directives

- Platform Identity: Open Nation (Civic Tech Governance & Leader Accountability)
- Brand Colors: Primary Royal Blue (`#2563eb` / Tailwind `blue-600`, hover `blue-700`), Dark Slate (`#0f172a`), High-contrast clean light theme.
- UI Consistency Rule: Always use standard Royal Blue (`bg-blue-600`, `text-blue-600`, `border-blue-600`, `hover:bg-blue-700`) as the primary brand color across all headers, scorecards, active tabs, buttons, icons, and focus rings. Avoid washed-out light sky-blue variants for primary branding elements.
- Navigation Design: Full-screen X/Twitter-inspired views (Headerless Compose, Sticky Search, Mobile Bottom Navigation).
- API Handling: Server-side Express proxy with resilient Gemini AI fallbacks.
